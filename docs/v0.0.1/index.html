GradieX Documentation

A feedforward neural network engine written from scratch in C++20 — no BLAS, no Eigen, no external dependencies — with Python bindings via pybind11.

#Getting Started

The engine is header-only, so the C++ side needs no build step of its own:

#include "core/network.h"

Then compile as a single translation unit:

clang++ -std=c++20 -O2 main.cpp -o main

For Python, build the extension module from the repository root:

pip install .

Then use it from Python:

import numpy as np, gradiex

net = gradiex.Network(learning_rate=0.5)
net.add_hidden(8, input_size=2, activation="tanh", init="xavier")
net.add_output(1, activation="sigmoid", loss="mse")
net.build()

history = net.train(X, Y, epochs=4000, shuffle=True, seed=42)

#Project State

This is version 2 of the engine, a rewrite of GradieX v1. The object hierarchy was flattened from Network → Layer → Neuron down to Network → Layer → vectors, and the weights were flattened into one contiguous array per layer to avoid per-neuron heap allocation.

It is not a superset of v1. Several features present there have not been carried across yet: model save and load, mini-batching, L2 weight decay, dropout, a train/validation split, seeded reproducibility, and a trainable softmax output. See Not Supported for the full list, and Known Bugs for defects that are documented rather than fixed.

The test suite under tests/ deliberately reports several failures. Those tests are executable specifications for the bugs above, each explaining the defect and the fix through FAIL_WITH_NOTE.

Performance work is tracked separately in TODO.md, ordered by measured payoff.
