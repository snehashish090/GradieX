#What v0.0.1 contains

  • The header-only C++20 engine in core/: a chain of hidden layers and one output layer, per-sample stochastic gradient descent, six trainable activations, five loss functions and three weight initializers.
  • The gradiex Python extension module, built with pybind11, exposing one Network class with NumPy input and output.
  • Unit tests for core/layer.h and core/network.h, plus a test suite for the Python bindings.
Not included

Model save and load, mini-batching, L2 weight decay, dropout, a train/validation split, seeded weight initialization, and a trainable softmax output. See Not Supported for the full list and Known Bugs for defects that are documented rather than fixed.

#Version numbering

Patch
Bug fixes and documentation corrections. No API change.
Minor
New features added in a backward-compatible way — a new activation, a new loss, a new keyword argument.
Major
Changes that break existing callers. While the major version is 0, the minor version may also break callers.

The version reported by the Python module always matches the directory these pages live in:

>>> import gradiex
>>> gradiex.__version__
'0.0.1'

#Publishing a new version

Run the helper from the repository root. It copies the current pages into a new directory, restamps the version throughout, marks older versions as superseded, and updates the table above.

python docs/newversion.py 0.0.2

Then update pyproject.toml and the __version__ string in python/gradiex_module.cpp to match, and rebuild with pip install -e .
