# GradieX Frontend

This frontend provides the GradieX landing page and serves downloadable build artifacts from `public/`.

## Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```

## Linux Binary Distribution Link

Place the compiled binary at:

```text
frontend/public/downloads/gradiex-linux-x86_64
```

The app exposes this at:

```text
/downloads/gradiex-linux-x86_64
```
